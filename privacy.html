Privacy Policy — Allie's Stuffy Shop

Allie's Stuffy Shop is a children's game for ages 6–8.

We collect no data. The game does not create accounts, does not use advertising, does not use third-party analytics, and does not track children's behaviour. All game progress (stars, coins, saved friends and outfits) — and the shopkeeper's name, which a player can set in the Profile screen — is stored only on the device itself, in on-device local storage, and never leaves the device.

No data is shared with anyone, because no data is collected.

Purchases: The launch version is completely free and contains no in-app purchases or subscriptions. We do not receive or store payment details, because no payment is taken in the launch version.

Profile and restarting: The game has no settings area and no parental gate. The shopkeeper's name is set in an open Profile screen. Restarting the shop also lives in the Profile screen, behind a clear warning and a second confirming tap; restarting erases saved stuffies and coins, and the shopkeeper's name is kept.

Pictures: A child can save a picture of a finished stuffy from the Done and Delivered screens. That picture is drawn from the game itself — the app has no camera or photo feature — and it is never uploaded or sent anywhere.

Contact: Questions about this policy can be sent to the developer at alvinangbs@gmail.com.
